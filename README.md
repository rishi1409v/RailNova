 **RailNova**
AI-Powered Smart Railway Assistance Platform


## 📌 Project Overview

RailNova is a Smart Indoor Railway Navigation System designed to help passengers navigate railway stations efficiently. It provides route guidance, train information, crowd monitoring, AI-powered assistance, and real-time station updates through a modern web platform.

The project aims to reduce passenger confusion inside railway stations and improve the overall travel experience through digital navigation and intelligent assistance.

---

## 🎯 Problem Statement

Passengers often face difficulties in:

- Finding the correct platform
- Locating station facilities
- Understanding station layouts
- Managing crowd congestion
- Accessing train information quickly

RailNova addresses these challenges by providing a centralized smart navigation solution.

## 🚀 Installation

Clone Repository

```bash
git clone https://github.com/your-username/RailNova.git
```

Move into project

```bash
cd RailNova
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production version

```bash
npm run build
```

---

## ⚙ Environment Variables

Create a `.env` file

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_key

VITE_GEMINI_API_KEY=your_gemini_api_key
```
